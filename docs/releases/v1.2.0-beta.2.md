# Prosody 1.2.0 Beta 2

Prosody 1.2.0 Beta 2 improves dictation readiness after launch and idle periods, adds smart sentence capitalization, and makes recovery and validation more reliable. It requires macOS 15 or later on Apple silicon. Speech model files are downloaded separately and are not included in the app.

## Highlights

- The installed speech model can prepare at launch and at the first dictation gesture. The tray pop-up shows **Preparing speech model…** with a progress indicator, and archive replay reuses the same loaded model.
- Cancel returns an unfinished dictation to idle immediately while an in-flight Core ML preparation can finish safely in the background.
- Live recognition and recovery replay use one shared model. If both recognition paths fail, captured audio is retained in Recovery instead of being discarded.
- The prepared model remains available for ordinary pauses and is released before recording/import or after five minutes idle.
- Smart sentence capitalization is enabled by default. It uses bounded caret context, preserves recognized casing when context is uncertain, and never reads secure fields.
- Queue status no longer reports **Queued** for the first utterance while capture is finishing.

## Install

Download `Prosody-1.2.0-beta.2.dmg` and `Prosody-1.2.0-beta.2.dmg.sha256`. Verify the checksum, open the disk image, and drag **Prosody** to **Applications**.

This public beta is ad-hoc signed and not notarized. macOS may block the first launch. Use the Finder context menu to choose **Open**, or allow Prosody in **System Settings → Privacy & Security**. The app contains no personal signing identity.

## Compatibility

The app keeps the `com.openai.clippy` bundle identifier so existing settings and model files are found. The ad-hoc public signature differs from earlier development-signed builds, so macOS may request Microphone, Screen Recording, or Accessibility permission again. Model files, transcripts, settings, and recovery data remain in their existing local locations.

## Validation

- 149 XCTest cases and 23 Swift Testing cases passed.
- `ProsodyValidation` passed.
- The quick release benchmark passed silence, tap, warm-cache cold start, warm dictation, and forced playback recovery. On the test Mac, the first command took 302.1 ms with an already warm Core ML cache, warm command median was 67.9 ms, and paragraph median was 125.9 ms. First-ever Core ML preparation remains machine-dependent.

## Known limitations

- The public beta is not notarized. First launch requires manual Gatekeeper approval.
- Physical microphone and every third-party editor cannot be automated in this environment. Focused insertion checks covered AppKit fields, TextEdit, Safari, and VS Code. Notes editing remains unverified.
- The speech model and optional speaker model are downloaded after installation and require internet access and additional disk space.
