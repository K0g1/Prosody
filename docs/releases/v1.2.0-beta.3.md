# Prosody 1.2.0 Beta 3

Build 15 requires macOS 15 or later on Apple silicon.

- Fixed a crash when macOS replied to the first microphone permission request. Dictation and microphone-only recordings now use audio-only capture. Dictation Settings shows whether the shortcut and microphone are ready.
- Import older Prosody or Clippy preferences from Settings → General. This build starts with its own defaults and preserves its preferences across signed in-app updates.
- Native glass includes blue, sea, smoked, amber, iris, and rose palettes, plus untinted Clear Glass, in the recorder, Settings, Transcripts, and dictation overlay.
- Settings can omit spoken hesitations in new dictations and saved transcripts while preserving sentence capitalization.
- Install Parakeet Unified, Parakeet TDT v3, or Fluid Speech Pro on demand. The Models page opens the cache in Finder and confirms deletions.
- Import multiple audio files with a shared label and filename preference. Shift-click or Command-click transcripts to copy or export them together.
- Choose Markdown fields in Transcript Export settings. Labels can save separate formatted Markdown, text-only Markdown, or raw text copies.
- Playback highlights the full reader width and begins centering passages just before their start. Retained audio shows its storage size and supports confirmed lossy compression.
- Shortcuts actions can control recording, use saved transcripts, and transcribe audio. The optional CLI runs in the open app with the same selected model and can manage saved replacements.

The public build uses an ad-hoc signature. Follow the [installation instructions](../USING_PROSODY.md#install) for first launch. Speech models download separately. Parakeet Unified provides live transcription during recording. Both multilingual models process a recording after it finishes.

## Validation

The macOS test suite, ProsodyValidation, and the packaged CLI integration test
passed. The integration test exercised file transcription, persistent
replacements, Markdown output, recovery from a mixed-success import, and
service shutdown. Native testing on macOS 15 covered the microphone permission
flow, live recording, dictation delivery into an editor, batch import and export,
glass palettes, manual preferences import, and playback highlighting. A signed
test update installed and relaunched with its saved theme. The disk image passed
signature, mounted-bundle, and SHA-256 checks. The signed bundle includes
Shortcuts action metadata.

Both additional models passed download, offline inference, and deletion
checks. Fluid Speech Pro omitted passages in one generated long-audio test.
The publisher’s sample runner also omitted passages on that input.
