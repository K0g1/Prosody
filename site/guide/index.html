Prosody handbook

Record system audio or your microphone, transcribe on your Mac, dictate into the app you are already using, and keep searchable Markdown transcripts.

Press ⌘F in your browser to find a feature or setting on this page. Try “Include Dictation,” “primary label,” or “Accessibility.”

Use the table to find the shortest path to the job you want to do. Settings search can also find a control by name or intent.

Build and source

Prosody requires macOS 15 or later and Apple silicon. Download the Beta 3 disk image and checksum from GitHub Releases.

Install

  1. Verify the checksum with shasum -a 256 -c Prosody-1.2.0-beta.3.dmg.sha256.
  2. Open the disk image and drag Prosody to Applications.
  3. If macOS blocks the first launch, choose Open from the Finder context menu or allow Prosody in System Settings → Privacy & Security.

Upgrade notes

The public beta keeps the `com.openai.clippy` bundle identifier so existing data is found. Its ad-hoc signature differs from earlier privately signed builds, so macOS may request capture and Accessibility permission again.

First run

First setup

A normal launch puts Prosody in the menu bar without opening a main window. Click the menu bar item to open the recorder, then choose Settings.

  1. Download the speech model. Open Settings → Models and choose Download beside Parakeet Unified. The download needs an internet connection; recognition runs locally on your Mac.
  2. Choose an audio source. Open Settings → Audio and set Default source to System Audio, Microphone, or System + Mic.
  3. Request capture access. In the same Audio page, choose Request Permissions and allow the selected sources in macOS.
  4. Enable dictation. Open Settings → Dictation, choose Enable… for Accessibility, return to Prosody, and choose Check Again.
  5. Choose where files go. Use Settings → Output → Choose… to change the default folder. A primary label can override it.

Find a setting without browsing

In Settings, press ⌘F, type a control name or a word that describes the job, use the Up and Down Arrow keys to choose a result, and press Return. Press Escape to clear the search. Settings search opens the section and scrolls to the matching control.

macOS access

Permissions and troubleshooting

Enable only the grants needed for the features you use. macOS stores these grants by app identity, so use the installed copy in Applications and keep one copy of the app.

FeatureSystem Settings → Privacy & Security
Record the microphone or dictateMicrophone
Record system audioScreen & System Audio Recording
Use the dictation shortcut and insert text into another appAccessibility

For Accessibility, open Settings → Dictation → Enable…. Turn on the Prosody app in System Settings, return to Prosody, and choose Check Again.

If a permission is on but capture still fails

  1. Quit and reopen the installed copy in Applications.
  2. Open System Settings → Privacy & Security and remove any stale entry for an older copy or signing identity.
  3. Enable the current app in the required pane. If macOS asks you to quit and reopen, do so.
  4. Retry capture, or return to Settings → Dictation → Check Again.

For a first-open warning from macOS, see Install the app. Capture and Accessibility grants apply after the app opens.

Menu bar recorder

Menu bar and Tray Elements

The menu bar item is the main recorder. Click it to open the popover. Right-click or Control-click it for a quick menu. The app menu also exposes the main windows and shortcuts.

Left-click

Open the recorder popover. Choose a source, title, labels, note template, or save location; then start, pause, resume, or finish a recording.

Right-click or Control-click

Open the quick menu for Show Prosody, Browse Transcripts…, Transcribe Audio Files…, recording controls, Settings…, and Quit Prosody.

The popover keeps Transcripts, Settings, and a More actions menu pinned at the bottom. The menu bar icon gains a small recording indicator while capture is active.

Choose optional elements

Open Settings → Tray Elements. These optional recorder elements are visible by default:

  • Logo and app name
  • Recording title
  • Recording labels
  • Audio source
  • Note template
  • Save location
  • Recent recordings (up to three)

Turning an element off hides it from the recorder without changing the saved choice behind it. Recording actions, status, and recovery notices stay visible. Choose Show All Controls to restore the optional elements.

Launch Prosody at Login

Open Settings → General and enable Launch Prosody at Login. If Prosody reports that approval is needed, choose Open Login Items…, approve it in System Settings, and return to Prosody to check the status.

Capture

Record audio

  1. Open the menu bar item.
  2. Choose Audio → System Audio, Microphone, or System + Mic.
  3. Optionally enter a Recording title and choose Labels. If automatic notes are on, choose a Template. Check Save to; choosing a folder there updates the primary label’s folder, or the default folder if there’s no primary label.
  4. Choose Start Recording. The status changes to Recording and the timer begins.
  5. Choose Pause to skip a portion, then Resume when ready. Choose Finish to stop and save.

After a successful save, a notice appears with View for the new transcript. It clears automatically after about five seconds; starting another recording also clears it.

Recording options

Live transcription

On by default. Text appears while you record. Turn it off in Settings → Transcription to transcribe after you finish and reduce processing during capture. The choice applies to the next recording.

Keep original audio

Off by default. Turn it on in Settings → Audio to retain source audio for playback in Transcripts. Recovery audio is still written temporarily while a recording is in progress.

Recording quality

Efficient uses less disk space; High preserves more detail. Choose the quality in Settings → Audio.

Transcript layout

In Settings → Transcription → Transcript layout, Maximum words per block defaults to 40 (10–100) and Pause before new block defaults to 1.5 seconds (0.5–5). Changes apply to the next transcription.

Speakers and notes after recording

Settings → Speakers controls speaker differentiation. Basic separates your microphone from system audio; Full attempts to separate individual speakers after the transcript is saved and may download a separate model. If that pass is unavailable, source labels are kept.

If Generate notes automatically is on, notes are created after the transcript and any speaker pass. Dictation never creates notes.

Most settings are locked while a recording or processing pass is active. Appearance, Tray Elements, and transcript layout remain editable.

Speak into another app

Dictation

Dictation turns speech into text in the focused text field. It uses the selected microphone and your Word Replacements. It does not generate notes.

Set up dictation

  1. Install Parakeet Unified in Settings → Models.
  2. Open Settings → Dictation.
  3. Choose Enable… for Accessibility, turn on the app in System Settings, then return and choose Check Again.
  4. Confirm that Microphone access is enabled in System Settings → Privacy & Security.
  5. Keep the destination field focused. Hold Right Command, speak, and release the key.

Activation and appearance

ControlChoices and defaults
ShortcutRight Command (default), Right Option, or Control + Option + Space
ActivationHold to talk (default) or Press to start / stop
Pop-up appearanceStandard (default) or Minimal, with a smaller waveform and status
Text insertionStandard paste (default) or Keyboard typing
Smart sentence capitalizationOn by default. Uses caret context when the editor makes it available.
Copy output to clipboardOff by default

In Press to start / stop mode, press once to start and again to finish. The recording hotkey in General is separate.

Dictate again immediately

Release the shortcut after one phrase, then press it again to start the next. In toggle mode, stop one dictation and use the next press to start another. Capture can start while the previous result is still being prepared or sent. A small queue keeps results in release order; if it fills, let a result finish before trying again.

Delivery and fallback

  • Standard paste sends Command-V after the shortcut modifiers are released. Prosody checks that the original destination is still safe. Keep the intended field focused; switching apps, fields, or moving the caret can prevent insertion. The app can account for a caret move caused by its own earlier insertion when the editor provides enough information.
  • With Copy output to clipboard off, Standard paste restores the prior clipboard if it is still unchanged. Turn the setting on to keep the dictated text on the clipboard.
  • Keyboard typing is a compatibility mode for editors that block paste. It types the text in chunks and checks that the destination is still current.
  • Smart sentence capitalization works with both insertion methods. Prosody leaves the recognized casing alone if the editor does not provide enough caret context, and does not read secure fields.
  • Delivered and copied dictation text gets one trailing space. The transcript saved in Transcripts stays clean.
  • If Prosody cannot safely insert the text, use Copy Text when the result panel appears, then paste into the field yourself.
  • Prosody does not retry a paste after it has already been dispatched. Secure input, remote desktops, and custom editors can still reject the event.
  • Preparing speech model… means the local model is still loading. Press Escape to dismiss unfinished dictation immediately. Text already being delivered is not undone.
  • If recognition fails and usable audio was captured, use Recover in the recorder to try again from the saved audio.
  • A very short tap or a dictation with no recognized text creates no output and returns to idle.

Completed dictations are saved in Transcripts. Turn on Include Dictation in the sidebar to see them.

Find, copy, import, recover

Transcripts, exports, imports, and recovery

Open Transcripts from the recorder footer or choose Browse Transcripts… in the menu bar quick menu. Start, pause, resume, and finish recordings in the menu bar recorder.

Search and sort

  • The left sidebar searches recording names and labels.
  • Use the Label filter to show one label or All labels. The default sort is Newest first; you can also sort by oldest, recording name, longest, shortest, or label.
  • Include Dictation is off by default. Turn it on to browse saved dictation history alongside recordings and imports.
  • With retained audio and Without retained audio are both checked by default. Uncheck one to show only the other; the app prevents you from clearing both.
  • The transcript detail search finds text and speaker names inside the selected transcript. Search filters the visible rows and suspends follow; clear the query to restore the previous follow choice.

Copy and open

Copy Raw

Copies plain speech with one blank line between blocks. It leaves out timestamps and speaker names.

Copy Markdown

Copies the formatted transcript, including its Markdown structure and labels.

More transcript actions

Use the ellipsis menu for Rename Speakers, Regenerate Notes, Open Notes, and Reveal in Finder.

Play audio and follow the transcript

Open a transcript with retained audio. Click Play, click a timestamp to jump to that passage, or drag along the timeline to scrub. The arrows next to the timeline jump five seconds at a time.

When the button reads Following, the reader highlights the current passage and scrolls with the audio. Scrolling by hand or searching suspends follow so the reader stays where you’re reading. While a search is active, Follow Audio is disabled; clear the search first. An explicit scrub still moves the highlighted row when no search is active, even if automatic follow is off. You can read, search, and copy transcripts without audio.

The timeline shows where speech occurs, skips duplicate echo text, and leaves trailing silence blank after the last visible speech time. Long sessions load audio as needed for playback, and the skip controls move five seconds. Closing the transcript window stops playback. A session without retained audio, or with missing audio files, stays readable and searchable and shows an explicit unavailable-audio state.

Transcribe an audio file

Choose File → Transcribe Audio Files…, select one or more files, and click Transcribe. Choose an optional label and filename preference in the file panel. Common formats include MP3, WAV, M4A, CAF, AIFF, and FLAC. Enable Settings → Audio → Keep original audio before importing if you want a playable copy saved with the transcript.

Recover an unfinished recording

Prosody writes a recovery journal and temporary audio while recording. If the app or Mac stops unexpectedly, the next launch can show an Unfinished recording notice in the recorder.

  1. Open the menu bar item and find the unfinished recording notice.
  2. Choose Recover to finish the transcript, optional speaker pass, notes, and retained audio.
  3. To discard it, choose Delete…, then confirm with Delete Recording.

Delete a finished recording

Right-click a recording in Transcripts or a recent recording in the recorder, choose Delete Recording…, and confirm. This removes the transcript, notes, and saved audio for that recording. It cannot be undone.

Organize by course, project, or series

Labels, names, colors, folders, and the primary label

Labels organize recordings and can control the recording name, Markdown filename, and save folder. A recording can have several labels; the first selected label is the Primary label.

Create or edit a label

  1. Open Settings → Labels.
  2. Choose Add Label or select an existing label in Library.
  3. Enter a Label name of up to 80 characters. Names must be unique without regard to case.
  4. Choose a Color with the color picker or enter a six-digit hex value such as #5676D9.
  5. Under Naming, set the File naming pattern and Date format. Check Preview for the resulting title and Markdown filename.
  6. Under Saving destination, check the folder path. Choose Choose Folder… for a custom destination or Use Default Folder to clear it.
  7. Choose Create Label for a new label or Save Changes for an existing one.

Unsaved drafts stay in Labels as you switch labels or Settings pages. Use Discard Changes to restore a saved label or Cancel to drop a new draft. A new label starts with the default output folder, the pattern {title}, and the date format yyyy-MM-dd.

Filename tokens

Use Insert to add a token, or type a pattern such as {date} - {title}. Each recording gets its own session folder; the pattern sets the recording title and Markdown filename.

{title}{label}{date}{time}{year}{month}{day}{weekday}{id}

Dates use local time. yyyy is the year, MM the month, dd the day, and MMM the short month. {time} uses HH-mm-ss. Unknown tokens and an empty date format for {date} block saving.

Choose labels and make one primary

  1. Open the menu bar recorder and choose Labels.
  2. Turn on each label you want on the next recording.
  3. Choose Make Primary beside a selected label. The primary label controls the recording name pattern and save folder.
  4. Choose Done. The recorder shows the primary label and a count of additional labels.

For a saved recording, open it in Transcripts and choose Labels. Select the labels, then choose Save Labels. This updates the labels in the transcript and Markdown; existing files keep their names and locations.

Deleting a label removes it from future choices but keeps saved recordings and their label snapshots. The delete confirmation explains this before you commit.

Notes, speakers, and privacy

Notes

Open Settings → Notes. Generate notes automatically is on by default. Notes are created after the transcript and any speaker pass. Dictation never creates notes.

ProviderWhat it does
Offline Outline (default)Organizes the transcript locally without an AI model.
Local OpenAI-CompatibleConnects to a local server such as LM Studio or Ollama. The default base URL is http://127.0.0.1:1234/v1 and the default model is qwen3-4b.
OpenAI (remote)Available only when Local-only mode is off. Generating notes sends the transcript text to the remote provider.

For a server provider, enter the model ID and base URL, choose Save API Key if needed, and choose Test Connection. The API key is stored in the macOS Keychain and kept out of session files. If a provider is unavailable, Prosody saves an offline outline and warns that it is not an AI summary.

When automatic notes are on, use Template in the recorder. Choose from Lecture Notes (default), Meeting Minutes, Study Notes, Cornell Notes, Summary, Action Items, and Transcript Only.

To regenerate notes, open the transcript, choose the ellipsis menu, and choose Regenerate Notes. Use Open Notes to open the saved notes.md.

Word Replacements

Open Settings → Replacements and choose Add Replacement. Enter the Recognized as text and the Replace with text. There are no rules on a clean install.

  • Rules match whole words or phrases without regard to case.
  • The longest matching phrase wins; duplicate originals use the first rule.
  • An empty replacement removes the matched word or phrase.
  • Rules apply to new recordings, imports, and dictations. Saved transcripts stay unchanged.
  • Replacements are literal text, so punctuation and regex-like characters are treated as text.

Speakers

Open Settings → Speakers → Speaker differentiation.

ModeResult
OffSkips speaker differentiation.
Basic (default)Separates your microphone from system audio.
FullAttempts to separate individual speakers after the transcript is saved. May download a separate model.

Rename speakers from the transcript ellipsis menu or by clicking a speaker name. Names update the transcript and are used for future note generation.

Hotkeys

Global recording shortcut is in Settings → General. The default is ⌥⌘R. Other presets are ⌃⌥R, ⌃⇧R, ⇧⌘R, and ⌃⌥C. Dictation uses its own shortcut in Settings → Dictation.

Privacy

  • Audio capture and speech recognition run on your Mac with the downloaded speech model.
  • Offline Outline notes are local. Local OpenAI-Compatible notes go to the local server you configure.
  • When you generate notes with a remote provider, it receives transcript text and context such as the title, speaker names, and timestamps. Speech recognition still runs on your Mac.
  • Local-only mode is on by default and blocks non-local notes providers. It does not block downloading speech models.
  • Remote notes endpoints must use HTTPS; plain HTTP is limited to loopback addresses. Redirects are not followed.
  • API keys are stored in the macOS Keychain. Session files contain transcript and settings metadata, not the key.
  • Transcripts, recovery files, and model caches are stored locally. Back up the folders you use.

How the pieces fit

Architecture

Prosody is a Swift Package Manager app with an AppKit shell and a SwiftUI interface. ProsodyApp hosts the interface, ProsodyCore holds recording and transcription logic, and ProsodyValidation provides checks and benchmark tools.

Application shellMenu bar item, recorder popover, Settings and Transcripts windows, dictation panel.
AppModelMain-actor source of truth for recording, processing, selection, and user-visible state.
Capture and transcriptionScreenCaptureKit for system audio, AVFoundation for the microphone, and the local Parakeet engine.
Transcript pipelineStreaming assembly, chunking, echo removal, word replacements, and deferred file transcription.
Recovery and storageCheckpointed recovery journal, temporary audio archive, completed session store, and session index.
DictationThe next capture can start while earlier results finish in release order. Finalization is serial, and delivery checks the original destination before pasting or typing.
NotesLocal Offline Outline by default; optional local or remote OpenAI-compatible providers.

The Settings search index is built from the control declarations, so a matching result opens the right section and scrolls to the control. The app uses direct distribution so Accessibility-based dictation can observe the shortcut and deliver text to the focused app.

Session metadata stores an optional source kind so older manifests and indexes still decode. New sessions write recording, dictation, or file. Legacy dictation is inferred only from a strict set of historical fields; other old sessions are marked legacy and stay visible. Retained-audio presence is also optional until the library inspects the session’s files.

Files and backups

Local data and backup

Completed sessions go in the folder shown in Settings → Output, unless a primary label supplies another folder. A clean install defaults to ~/Prosody. Upgrades keep existing destinations, including ~/Clippy when it was the previous output folder.

Session folder

Contains the Markdown transcript, transcript.json, session.json, optional notes.md, and optional retained audio.

Application support

Prosody prefers the previous sandbox support folder at ~/Library/Containers/com.openai.clippy/Data/Library/Application Support/Clippy. Otherwise it uses ~/Library/Application Support/Clippy. Models and recovery data live under that folder. Preferences use the same macOS app identity, com.openai.clippy.

Keychain

Stores optional notes-provider API keys. They are not written into transcripts or session manifests.

Model cache

Contains downloaded speech and optional diarization model files. These can be downloaded again after a move.

What to back up

  • Finish any recordings, let processing complete, and quit Prosody before copying data.
  • Back up every output folder you use, including folders assigned to labels. Keep each session folder and its contents together. To find one, select the transcript and choose More Transcript Actions → Reveal in Finder.
  • Include the app’s support folder if you need unfinished recovery data or fallback sessions. macOS stores app preferences and Keychain entries separately.
  • The model cache is large but replaceable; include it only if you want to avoid downloading models again.

After moving or restoring an output folder, select it again under Output or in the label editor. Changing the output setting alone doesn’t move existing files.

Legacy sessions and upgrade identity

The old sandbox output folder can be ~/Library/Containers/com.openai.clippy/Data/Clippy. The one-time direct-distribution migration imports missing preferences.* values from the old sandbox plist and can select that sandbox output folder when no direct output preference exists. It does not move or delete saved recordings.

Distributed builds may retain the bundle identifier and signing identity for upgrades. A changed signing identity changes the designated code requirement and can require permission grants again. Uncertain legacy sessions remain visible rather than being silently hidden as dictation.

Speech model

Model availability

The Models page offers Parakeet Unified for English live transcription and Parakeet TDT v3 or Fluid Speech Pro for multilingual batch transcription. Each model downloads on demand and runs locally.

  • A distributed build contains no model weights. The app downloads the model after installation.
  • Select any installed model. Use Open Models Folder to inspect the cache, or the Delete button to remove a model after confirmation.
  • If a download is interrupted, choose Download again. Check free disk space and the network connection if it fails repeatedly.
  • Deferred transcription, imports, and dictation use the same local speech model.
  • Full speaker separation may need a separate model download. If it is unavailable, Prosody keeps source labels.

When something does not work

Troubleshooting

I cannot find the app.

Look for the Prosody icon in the macOS menu bar. Click it or reopen Prosody from Applications to show the recorder.

Start Recording is disabled.

Wait for the current recording, dictation, or processing pass to finish. Check that the speech model is installed and that the selected audio source has its macOS permission.

System audio is missing.

Choose System Audio or System + Mic, enable Screen & System Audio Recording, and reopen the installed app. Confirm that the source is playing and not muted.

The microphone is silent.

Choose the correct microphone in Settings → Audio, enable Microphone, and check the input level in macOS Sound settings.

No transcript appears after Finish.

Wait for Finalizing transcript… to finish. If Live transcription is off, the saved audio is transcribed after capture. A no-speech warning means the selected source did not produce recognizable speech.

Dictation does not insert text.

Check Accessibility and Microphone, keep the destination field focused, and choose Check Again. If the editor blocks paste, switch Text insertion to Keyboard typing. If a result panel appears, choose Copy Text and paste manually. Secure input and remote desktop apps can block insertion.

My dictations are missing from Transcripts.

Turn on Include Dictation in the sidebar. If you still don’t see the result, clear the title search and label filter and check both audio boxes. A canceled, very short, or silent dictation does not create a saved transcript.

The transcript scrolls away from where I’m reading.

Click Following to turn follow off, or scroll by hand to suspend it. Click Follow Audio when you want to return to playback. If a search is active, clear it first because Follow Audio is disabled while the transcript is filtered.

Settings are locked.

Most controls are unavailable while recording or processing. Appearance, Tray Elements, and transcript layout remain editable. Finish the current job and try again.

The output folder cannot be found.

Choose the folder again in Settings → Output or in the label editor. A primary label’s folder overrides the default output folder.

Notes did not use my provider.

Check the provider, model ID, base URL, and Test Connection. Turn off Local-only mode only if you intend to send transcript text to a remote provider. When a provider fails, Prosody saves an offline outline and labels it as such.

An unfinished recording appears.

Choose Recover to finish it or Delete… to discard it. Recovery is designed to preserve checkpoints after an unexpected stop.

The app will not launch.

Verify the DMG against the SHA-256 file attached to the release. This public beta is ad-hoc signed and not notarized, so macOS may require approval in System Settings → Privacy & Security.
