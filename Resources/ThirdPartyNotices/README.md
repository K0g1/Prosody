## Downloaded by Prosody

The app and any distributed build do not contain model weights. When needed, FluidAudio fetches models from Hugging Face and caches them on the Mac for local inference. The model terms are separate from the FluidAudio software license.

- **Speech recognition:** Fluid Inference publishes the [Parakeet Unified EN 0.6B Core ML conversion](https://huggingface.co/FluidInference/parakeet-unified-en-0.6b-coreml/blob/d32e972dd4315f1dc3f6be28fb2aab0ab3e80358/README.md), including INT8 encoder variants, and labels that export [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It is a conversion of [NVIDIA Parakeet Unified EN 0.6B](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md), which NVIDIA publishes under the [NVIDIA Open Model License Agreement](https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/). See both sources for terms and provenance. Clippy does not grant rights to redistribute either model.
- **Optional speaker identification:** Fluid Inference's [Speaker Diarization Core ML](https://huggingface.co/FluidInference/speaker-diarization-coreml/blob/7eab74f3463c736418d0eb10296261ae581146c9/README.md) provides the offline Community-1 models. These are modified Core ML conversions of [pyannote Speaker Diarization Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1), including WeSpeaker embeddings and [PLDA parameters from Brno University of Technology / BUT Speech@FIT](https://huggingface.co/BUT-FIT/diarizen-wavlm-large-s80-md/blob/6285693ddd5b38e8229acb93f864f3d04a82bee1/plda/LICENSE). See the [upstream notice](https://huggingface.co/FluidInference/speaker-diarization-coreml/blob/7eab74f3463c736418d0eb10296261ae581146c9/NOTICE.md) for attribution and the scope of the [included CC BY 4.0 license](Community-1-LICENSE.txt). Clippy uses the offline Community-1 path; the separate legacy online diarizer models have their own terms.
